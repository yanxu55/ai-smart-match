# Demo Instructions

## Quick Demo of SmartMatch Features

### 1. Web Interface Demo
```bash
streamlit run app.py
```

Then follow these steps:
1. **Create Student Profile**
   - Go to "Student Profile" page
   - Fill out sample data:
     - Name: "Alex Johnson"
     - Grade: 11
     - Interests: Technology, Environmental Science, Writing
     - Strengths: Problem Solving, Communication, Research
     - Values: Innovation, Social Justice, Environmental Sustainability

2. **Add New Activity**
   - Go to "Add New Activity" page
   - Create sample activity:
     - Name: "Green Tech Club"
     - Category: STEM
     - Description: "Develop technology solutions for environmental problems"
     - Skills: Programming, Environmental Science, Innovation
     - Scores: Growth=9, Impact=9, Fulfillment=8

3. **Get Recommendations**
   - Go to "Get Recommendations" page
   - Generate top 3 recommendations
   - View detailed reasoning and scores

### 2. Command Line Demo
```bash
python smartmatch_cli.py
```

Follow the menu options to:
- Create student profile
- Add new activity
- Generate recommendations
- Browse activity database

### 3. API Demo
```bash
python api_example.py
```

This demonstrates programmatic usage of the system.

### 4. Batch Processing Demo
```bash
python batch_processor.py
```

This creates sample input files and shows batch processing capabilities.
